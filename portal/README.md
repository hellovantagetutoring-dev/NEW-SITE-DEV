# Vantage Student Portal

Private class resources and schedule for Vantage Tutoring students and tutors.

## Local development

```bash
npm install
cp .env.example .env.local
# add Supabase keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

See [SETUP.md](./SETUP.md) for Supabase, auth, and deploy steps.
